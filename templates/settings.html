Weather-based collection estimate

Daily precipitation for an Indian place name, 6-digit PIN code or coordinates. Open-Meteo first, with NASA POWER filling any missing past days. No API key needed.

If coordinates are given they are used directly. Otherwise the place is looked up in India with Open-Meteo, then OpenStreetMap as a backup; a PIN code is first turned into its post office and district (a PIN covers a postal area, not an exact plot). Rainfall values are modelled grid estimates, not a local rain gauge: compare with IMD observations for field accuracy.

Weather data by Open-Meteo.com (CC BY 4.0) · backup rainfall from NASA POWER · backup locations © OpenStreetMap contributors
